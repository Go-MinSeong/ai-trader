# AI Trader

미국 주식의 장 초반 가격 범위 돌파(ORB) 전략을 **가상 자금으로 백테스트**하는 로컬 웹 UI입니다. 실제 증권 계좌나 브로커에는 연결하지 않습니다.

## 실행

```bash
uv venv
uv pip install -e .
uv run streamlit run app.py --server.address 127.0.0.1
```

브라우저에서 Streamlit이 안내하는 로컬 주소를 여세요. 설치 없이 화면을 확인하려면 왼쪽에서 `합성 예시 데이터`를 선택할 수 있습니다. 이 데이터는 임의로 만든 동작 확인용 데이터라 전략 성과 판단에 사용할 수 없습니다.

실제 전략 검토에는 직접 준비한 미국 정규장 5분봉 CSV를 올리세요. `examples/synthetic_5m.csv`와 같은 형식입니다.

```csv
timestamp,open,high,low,close,volume
2026-01-05 09:30,100,101,99,100,12000
```

시간대 정보가 없는 timestamp는 미국 동부시간으로 해석합니다. 입력은 한 티커의 정규장 5분봉을 권장하며, 행 순서와 무관하게 시간순 정렬됩니다.

## 계산 규칙

- 매일 첫 3개 봉의 고가/저가로 15분 시가 범위를 정합니다.
- 그 이후 종가가 시가 범위 고점을 넘으면 종가에 매수했다고 가정합니다. 하루 최대 한 번만 진입합니다.
- 손절은 시가 범위 중간값, 목표가는 사용자가 지정한 위험 배수(R)입니다.
- 수량은 현재 가상 잔고의 거래당 위험 한도와 현금으로 제한합니다.
- 진입/청산 슬리피지와 왕복 수수료를 반영합니다. 한 봉이 손절과 목표가를 모두 포함하면 손절이 먼저 체결된 것으로 계산합니다.
- 장 마감까지 목표나 손절에 도달하지 않으면 마지막 종가에 정리합니다.

승률 하나만으로 수익성을 판단하지 마세요. 결과는 표본 기간, 거래 횟수, 수수료, 슬리피지, 최대 낙폭과 함께 읽어야 합니다. 과거 시뮬레이션은 미래 성과를 보장하지 않습니다.
