시장 데이터 연결

시세만 읽어 옵니다. API 비밀 키는 Mac 키체인에 저장하며 주문 권한은 요청하지 않습니다.

Toss Securities WTS에서 발급한 개인용 키를 입력하세요. 저장된 키는 비워 두어도 연결 확인과 데이터 수집에 사용됩니다. 허용 IP 등록이 필요할 수 있습니다.
뉴스 조회는 WorldMonitor의 계정/요금제 허용량을 사용할 수 있습니다. 연결 확인은 도구 목록만 읽고, 뉴스는 별도 버튼을 눌러 조회합니다.
각 매수·매도 금액에 적용하는 가정치입니다. 거래세·환전 비용은 별도 반영되지 않습니다.
개인용 시세를 로컬에서만 캐시합니다. 분봉 이력 보관 범위는 API 제공 조건에 따르며, 실제 주문 기능은 없습니다.
